# Relógio Digital ⏱️

Este é um mini projeto de Relógio Digital desenvolvido com o objetivo de praticar conceitos fundamentais de HTML, CSS e principalmente JavaScript.
O relógio exibe horas, minutos e segundos em tempo real, com uma interface limpa, moderna e responsiva.

## Tecnologias Utilizadas
- **HTML:** estrutura simples e organizada  
- **CSS:** gradiente de fundo, sombras e foco na experiência do usuário  
- **JavaScript:** uso do `Date()`, atualização em tempo real com `setInterval()` e manipulação do DOM
